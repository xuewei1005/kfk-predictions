# KFK 2060 预言现实印证档案库 (Web App)

基于 2019 年豆瓣著名的“来自 2060 年的穿越者 KFK”全部 **282 条问答** 整理，并结合 2024-2026 年最新世界局势与现实事实构建的 **多维度筛选与现实印证考据应用**。

---

## 🌟 核心功能特性

1. **五大实现状态筛选 (Status Filters)**
   - **已实现 / 神准印证 (39条)**：如中国房价在 20 年代早期进入下行通道、远程办公普及、东京奥运会延期事故与女排未夺冠、台湾 2020 蔡英文连任、吴亦凡世纪塌房丑闻等。
   - **部分实现 / 趋势符合 (35条)**：如星链低轨卫星 WIFI 普及、AI 大模型跨行业渗透、新冷战对抗爆发、极端高温热炼破纪录、老人自费社区等。
   - **未实现 / 明显翻车 (4条)**：如 2020 年特朗普连任失败、2032 年夏季奥运会雅加达落选（布里斯班当选）、2047 年才达 80 亿人口（现实 2022 年即达到提前 25 年）。
   - **待验证 / 未来预言 (108条)**：如 2035 年全息交互游戏 OS、2038 年强 AI 量化生产、2039 年蔡英文去世、2048 年第三次世界大战爆发、日本迁都冈山等。
   - **无法验证 / 超验哲学 (96条)**：如时间观察者机制、造物主、定命论、灵界认知提升、KFK 个人背景问答。

2. **九大预言分类 (Category Filters)**
   - 🌍 **国际地缘与战争**
   - 🤖 **科技与人工智能**
   - 💰 **经济金融与房产**
   - 🌋 **气候环境与地理**
   - 👥 **社会职业与民生**
   - 🧬 **医疗健康与生命**
   - 🎬 **文化娱乐与体育**
   - ✨ **哲学灵学与信仰**
   - ⏳ **穿越设定与个人**

3. **四大年代跨度筛选 (Timeline Era)**
   - 2019 - 2020 年
   - 2021 - 2030 年代
   - 2031 - 2048 年代
   - 2049 - 2060 年代
   - 远期 / 超验未定年份

4. **三种交互视图切换 (Multi-View)**
   - **卡片网格视图 (Grid View)**：现代玻璃拟态卡片，含提问、原文回答、💡 预言核心提炼、🔍 现实印证核查评注。
   - **清单列表视图 (Table View)**：紧凑高密度数据表格，支持快速对照与浏览。
   - **编年时间轴视图 (Timeline View)**：按未来历史发展脉络排布的时间线，展现 KFK 所述“未来简史”。

5. **实用辅助功能**
   - 🔍 **全局实时搜索**：支持搜索问题、回答、预言提炼、现实考据评注或标签。
   - 🔥 **热门关键词速查**：一键速查“房价”、“特朗普”、“吴亦凡”、“东京奥运”、“远程办公”等核心热门预言。
   - 🎲 **随机看一条**：探索式随机浏览一条问答。
   - ⭐ **个人收藏夹**：收藏感兴趣的预言，支持单独筛选查看（基于 LocalStorage 持久化）。
   - 📥 **数据一键导出**：一键将当前筛选或全量数据导出为 JSON 格式。
   - 🌓 **暗黑/日光主题一键切换**：星际暗夜模式与清爽日光模式无缝切换。

## 📂 项目文件清单

| 文件名 | 说明 |
| :--- | :--- |
| `index.html` | 语义化 HTML5 页面结构，包含统计看板、多维过滤面板、卡片/表格/时间线视图与详情弹窗 |
| `style.css` | 现代响应式样式表，支持星际深色/明亮浅色双主题、玻璃拟态与流光徽章 |
| `app.js` | 响应式前端交互逻辑（全量实时搜索、多维度交叉过滤、排序、收藏夹、导出、弹窗导航） |
| `predictions_data.js` | 282 条预言完整全量静态数据包（开箱即用，免跨域限制） |
| `predictions.json` | 格式化 JSON 数据文件 |
| `extract.py` / `build_dataset.py` | 原始文章数据爬取、解析与多维度考证标注工程脚本 |
