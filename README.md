## 核查概览 / Verification overview

本项目不是简单判断“预言准不准”，而是结合预言目标年份、可观察事实和公开证据，将每条内容分为五类。以下统计对应网页当前使用的数据集。

This archive does not reduce every prediction to a simple true-or-false judgment. Each entry is classified using its target date, observable facts, and available public evidence. The figures below match the dataset currently used by the website.

- **已实现 / Fulfilled（39）**：代表性例子包括多数国家结婚率偏低、上证指数未达到 20,000 点，以及社会没有实行国家分配结婚对象。
  Examples include low marriage rates across many countries, the Shanghai Composite remaining below 20,000, and no state allocation of marriage partners.
- **部分实现 / Partially fulfilled（36）**：部分趋势或条件与现实相符，但时间、范围或结果不完全一致，例如全球不确定性与焦虑上升、房地产市场分化，以及特朗普 2020 年未连任但于 2024 年再次当选。
  Some elements align with reality while the timing, scope, or outcome differs—for example, rising global uncertainty and anxiety, a divided housing market, and Trump losing re-election in 2020 but returning to office in 2024.
- **未实现 / Unfulfilled（2）**：例如“2047 年全球人口达到 80 亿”这一时间判断明显提前，以及 2022—2023 年台海问题实现统一的判断未发生。
  Examples include the population milestone occurring much earlier than the predicted 2047 date and no unification taking place in 2022–2023.
- **待验证 / Pending（108）**：主要是尚未到目标年份的长期预言，例如 2048 年以前的交通方式、2060 年的政治体制变化和房屋价值变化。
  These are mainly long-term claims whose target dates have not arrived, such as transport before 2048 and political or housing changes by 2060.
- **无法验证 / Unverifiable（97）**：涉及发帖者身份、被删除的原问题或无法独立核实的叙事内容。
  These entries concern the poster’s identity, deleted source questions, or narrative claims that cannot be independently verified.
